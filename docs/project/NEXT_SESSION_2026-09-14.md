## 다른 컴퓨터에서 이어가기

저장소 https://github.com/ionic2001/diorama-stickerbook 의 main을 clone 또는 pull한다. 저장소 루트에서 Node.js/npm을 준비하고 npm ci, npm run verify, npm run dev -- --port 5174 순으로 실행한다. 위 주소 앞에 http://localhost:5174 를 붙인다.

node_modules와 dist는 업로드 대상이 아니다. 서비스용 이미지는 저장소에 포함되어 일반 실행에 이미지 재생성이 필요 없다. 이미지 재생성 스크립트는 별도의 sharp 설치 환경이 필요하다.

브라우저에 저장한 작품은 GitHub로 이전되지 않는다. 기존 컴퓨터의 작품 데이터는 별도 이전이 필요하고 PNG는 편집 가능한 작품 백업이 아니다. API 키/광고 계정 설정은 저장소에 넣지 않는다.

앞으로 작업 시작 시 사용할 모델을 먼저 안내한다. 모델 변경은 실제 선택 상태를 확인하고, 자동 전환했다고 가정하지 않는다.
