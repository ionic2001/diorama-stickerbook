## 1. 제품 정의

Diorama Stickerbook은 빈 3D 아이소메트릭 공간에 투명 스티커를 배치해 사용자가 자신만의 장면을 꾸미고 PNG 이미지로 저장하는 힐링 웹 애플리케이션이다. 설치와 계정 없이 브라우저에서 바로 사용하며 작업은 테마별로 현재 브라우저에 저장한다.

## 2. 현재 제공 범위

- 온실 정원 테마와 팔레트에 등록된 16개 스티커
- 비 오는 밤의 카페 테마와 29개 스티커 자산
- 클릭 및 드래그로 스티커 추가
- 이동, 크기 조절, 회전, 좌우 반전, 잠금, 복제, 삭제
- 레이어 앞뒤 이동과 맨 앞·맨 뒤 배치
- 실행 취소와 다시 실행
- 보조선, 편집·감상 모드, 테마별 자동 저장과 초기화
- Web Audio 기반 배경음과 효과음
- 배경과 스티커를 합성한 PNG 내보내기

제공 수량은 각 테마 매니페스트와 실제 화면의 팔레트를 기준으로 기록한다. 원본 장면은 1200×896으로 정확한 4:3이 아니며, 1024×768 논리 캔버스에 X축과 Y축을 각각 환산해 표시한다. `scale: 1`은 매니페스트에 기록된 캔버스 크기를 그대로 사용한다는 의미다.

## 3. 기술 및 데이터 정책

- React, TypeScript, Vite 기반 단일 페이지 앱
- 서버와 사용자 계정 없이 localStorage에 테마별 작업 저장
- 외부 음원 전송 없이 Web Audio API로 사운드 생성
- 내보내기는 브라우저 안에서 처리
- 콘텐츠는 테마 매니페스트와 `public/assets/diorama` 자산으로 관리
- 스티커 추출 도구의 직접 의존성은 개발 의존성으로 고정

## 4. 완료 기준

- 새 환경에서 `npm install`, `npm run verify` 통과
- 두 테마에서 추가·이동·크기·회전·반전·복제·삭제 확인
- 테마 전환 후 각 테마 작업이 독립적으로 복원됨
- 초기화, 실행 취소·다시 실행, PNG 내보내기 확인
- 데스크톱과 모바일에서 캔버스·트레이·도구 모음 조작 가능
- 공개 배포 전 모든 이미지 자산의 사용·배포 권리 기록

## 5. 다음 우선순위

1. 실제 브라우저에서 두 테마의 전체 편집 흐름과 PNG 결과를 검수한다.
2. 작은 화면에서 트레이와 선택 도구가 가려지지 않도록 모바일 UI를 보완한다.
3. 한국어로 고정된 확인·오류 문구와 테마 제목의 다국어 정책을 결정한다.
4. 세 번째 테마를 추가하기 전에 매니페스트 등록 방식을 배열 또는 레지스트리로 일반화한다.
5. 저장 데이터 버전 마이그레이션과 손상 데이터 복구 방식을 추가한다.
6. 독립 배포 주소, 제품명, 공유 이미지와 검색 노출 정책을 확정한다.
