# Diorama Stickerbook 최종 기획서

## 최신 기획 변경 — 2026-09-14

이 절이 이전 난이도·스티커 수량·팔레트 재사용 기획보다 우선한다. 이번 변경은 기획 문서에만 반영했으며 현재 화면과 편집 기능은 아직 이전 구현이다.

### 콘텐츠 구성

- 초급·중급·고급의 3단계 구성을 폐지하고, 모든 세트를 고급 수준의 세부 오브젝트로 구성한다.
- 난이도 선택 화면과 난이도별 콘텐츠 분기는 제거하는 것으로 계획한다. 고급은 콘텐츠의 세밀함을 뜻하며 별도 선택 옵션이 아니다.
- 각 세트는 독립적으로 배치 가능한 스티커를 최소 75개 이상 제공한다. 3개 테마 × 테마당 2개 세트의 출시 목표는 유지한다.
- 같은 스티커의 복제 횟수나 하나의 합쳐진 이미지 안에 그려진 소품 수로 최소 수량을 채우지 않는다. 개별 배치 가능한 콘텐츠 항목을 기준으로 센다.
- 기존 초급 25개·중급 50개·고급 100개 상한은 폐기한다. 새 상한은 미정이며, 75개 이상 기준을 충족한 상태에서 성능 검증 후 결정한다.
- 가구·식물·도구·소품·세부 장식을 개별적으로 배치할 수 있도록 구성하되, 분리 단위와 새 디자인은 제작 전에 확인받는다.
- 기존 온실 9종은 제작 방식 검증용 시제품이며 최소 75개 완성 세트로 간주하지 않는다.

### 오른쪽 스티커 목록

- 목록은 전체 보유 스티커가 아니라 현재 작품에서 아직 사용하지 않은 스티커를 보여준다.
- 클릭 또는 드래그로 캔버스에 배치가 성공한 스티커는 즉시 목록에서 제외한다. 배치 취소·실패만으로는 제외하지 않는다.
- 캔버스에 남아 있는 사용 여부를 기준으로 판단한다. 선택 해제·잠금·이동·회전·크기 변경은 목록 복귀 사유가 아니다.
- 삭제하면 다시 사용할 수 있도록 원래 분류·정렬 위치로 돌려놓는다. 실행 취소/다시 실행도 캔버스와 목록을 함께 복원한다.
- 초기화 시 기본 작품 상태를 기준으로 목록을 다시 계산한다. 기본 배치가 있는 시제품은 그 스티커를 처음부터 목록에서 제외한다.
- 저장 후 재방문에도 작품에 배치된 항목은 숨긴다. 사용 여부를 별도 저장하지 않고 복원한 작품의 스티커 목록에서 계산해 불일치를 방지한다.
- 세트별로 독립 적용하며 검색·분류 결과에도 사용한 스티커를 표시하지 않는다.
- 모두 사용하면 “모든 스티커를 배치했어요. 작품에서 스티커를 삭제하면 다시 선택할 수 있어요.”라는 안내를 제공한다.

### 일관성을 위한 구현 기본안

- 한 콘텐츠 항목은 작품에 한 번 배치하는 방식으로 계획한다. 목록의 재추가뿐 아니라 복제 기능도 제한한다. 이 복제 제한은 사용 후 목록에서 제외하는 경험을 일관되게 만들기 위한 기본안이다.
- 같은 모양을 여러 개 제공해야 한다면 세트 안의 별도 항목으로 명시적으로 구성한다.
- 기존 작품에 동일 자산의 복제본이 있어도 자동 삭제하지 않는다. 하나라도 남아 있으면 해당 자산을 목록에서 숨기고, 마지막 복제본 삭제 시 복귀시킨다.
- 기존 저장 ID를 임의 변경하거나 사용자 작품을 초기화하지 않는다.

## 1. 제품 정의

Diorama Stickerbook은 빈 3D 아이소메트릭 공간에 투명 스티커를 배치해 사용자가 자신만의 장면을 꾸미고 PNG 이미지로 저장하는 힐링 웹 애플리케이션이다. 설치와 계정 없이 브라우저에서 바로 사용하며 작업은 테마별로 현재 브라우저에 저장한다.

## 2. 현재 제공 범위

- 온실 정원 테마와 팔레트에 등록된 16개 스티커
- 비 오는 밤의 카페 테마와 29개 스티커 자산
- 클릭 및 드래그로 스티커 추가
- 이동, 크기 조절, 회전, 좌우 반전, 잠금, 복제, 삭제
- 레이어 앞뒤 이동과 맨 앞·맨 뒤 배치
- 실행 취소와 다시 실행
- 보조선, 편집·감상 모드, 테마별 자동 저장과 초기화
- Web Audio 기반 배경음과 효과음
- 배경과 스티커를 합성한 PNG 내보내기

제공 수량은 각 테마 매니페스트와 실제 화면의 팔레트를 기준으로 기록한다. 원본 장면은 1200×896으로 정확한 4:3이 아니며, 1024×768 논리 캔버스에 X축과 Y축을 각각 환산해 표시한다. `scale: 1`은 매니페스트에 기록된 캔버스 크기를 그대로 사용한다는 의미다.

## 3. 기술 및 데이터 정책

- React, TypeScript, Vite 기반 단일 페이지 앱
- 서버와 사용자 계정 없이 localStorage에 테마별 작업 저장
- 외부 음원 전송 없이 Web Audio API로 사운드 생성
- 내보내기는 브라우저 안에서 처리
- 콘텐츠는 테마 매니페스트와 `public/assets/diorama` 자산으로 관리
- 스티커 추출 도구의 직접 의존성은 개발 의존성으로 고정

## 4. 완료 기준

- 새 환경에서 `npm install`, `npm run verify` 통과
- 두 테마에서 추가·이동·크기·회전·반전·복제·삭제 확인
- 테마 전환 후 각 테마 작업이 독립적으로 복원됨
- 초기화, 실행 취소·다시 실행, PNG 내보내기 확인
- 데스크톱과 모바일에서 캔버스·트레이·도구 모음 조작 가능
- 공개 배포 전 모든 이미지 자산의 사용·배포 권리 기록
