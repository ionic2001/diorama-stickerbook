# 작업대 시제품 연결

중급 5종을 `/studio/?set=glasshouse-botanist&pilot=workbench`에 연결했다. 영어는 `/en/studio/?set=glasshouse-botanist&pilot=workbench`다. 일반 테마 팔레트와 기존 저장 데이터는 변경하지 않는다.

빈 작업대와 씨앗 상자를 내장 이미지 생성 도구로 보정했다. 작업대는 둥근 손잡이·곡선 뒤 선반, 씨앗 상자는 왼쪽 면이 보이는 원근으로 수정했다. 최초 보정본에 불투명 배경이 생겨 배경 추출을 추가 요청했고, 최종 PNG는 실제 알파 채널과 투명 모서리를 확인했다. 최종 파일은 `public/assets/diorama/glasshouse-workbench-pilot/`에 저장했다. 기존 v1 원본은 유지한다.

시제품은 5개 부품이 배치된 상태로 시작하며 각각 이동·회전·크기·레이어·삭제·복제할 수 있다. 초기화는 시제품의 기본 조립 상태로 돌아간다. 저장 ID는 `glasshouse-workbench-intermediate-pilot-v1`이며 기존 온실·선반 저장 ID와 다르다.

도구 트레이도 작업대에 맞춰 낮은 시점과 가로 방향으로 보정했다. `tools-v2.png`를 연결하고 기본 크기를 125 × 41.67로 조정했다. 기존 자산과 저장 ID는 유지한다. 모든 소품을 동일한 카메라로 다시 그린 것은 아니므로 최종 콘텐츠 통일성 검토는 남아 있다. 이 연결은 기능 검증용 시제품이며 중급 전체 구성 완료나 성능 검증 완료를 의미하지 않는다.

트레이 보정은 내장 이미지 생성 도구로 진행했다(CLI 미사용). 두 번의 편집 결과에 격자무늬 배경이 남아 제외하고, 아래 프롬프트로 새로 생성한 최종 PNG의 알파 채널과 투명 모서리를 확인했다. 이동·회전·자동 저장과 재로드·기존 저장 분리·PNG 내보내기·모바일 회전 버튼·영어 진입 검사를 통과했다. `qa/studio.png`는 기본 배치이고 `qa/export.png`는 테스트에서 트레이를 이동·회전한 결과다.
