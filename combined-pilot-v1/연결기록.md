# 온실 중급 통합 시제품 9종

- 한국어: `/studio/?set=glasshouse-botanist&pilot=combined`
- 영어: `/en/studio/?set=glasshouse-botanist&pilot=combined`
- 선반 4종과 작업대 5종의 승인된 기존 PNG를 재사용한다. 새 그림이나 디자인 변경은 없다.
- 선반은 왼쪽, 작업대는 오른쪽에 배치하며 작업대 그룹의 초기 배율은 0.85다. 모든 부품은 개별 편집이 가능하다.
- 저장 ID는 `glasshouse-combined-intermediate-pilot-v1`이다. 기존 온실, 선반, 작업대 시제품 저장 ID와 분리한다. 기존 작품을 자동으로 합치거나 덮어쓰지 않는다.
- 일반 테마 메뉴에는 아직 노출하지 않는 미공개 시제품이다. 한국어·영어 작업실 및 기존 PNG 저장·음악 기능을 재사용한다.
- 전체 빌드, 기존 도메인·정적 페이지 검사와 9종 자산의 고유 ID·실제 파일·기본 배치·기존 시제품 불변 검사를 통과했다. 이번 단계에서 브라우저 조작 검사는 새로 수행하지 않았다.
- 중급 전체 세트 완성이나 최대 스티커 수 성능 검증 완료를 의미하지 않는다. 다음은 통합 배치 확인 후 난이도별 분리 구성을 정리하는 단계다.
