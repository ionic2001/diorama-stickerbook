# 흰 테두리 제거

첫 8종은 내장 이미지 생성 도구를 사용했다. 마지막 도구 트레이는 사용자 승인 후 원본 픽셀의 알파 채널을 코드로 편집했다.
선반 4종과 작업대·흙·씨앗·화분 4종을 각각 원본과 같은 폴더의 `*-borderless.png`에 저장하고 개별·통합 시제품에 연결했다. 원본, 자산 ID, 저장 ID, 배치 수치는 유지했다. 생성 편집 특성상 미세한 질감과 형태 차이가 있을 수 있다.

8종의 실제 RGBA 및 투명 모서리를 확인했다. 도구 트레이는 이미지 생성 보정본 대신 원본 `tools-v2.png`에서 외부 경계의 밝은 픽셀을 투명하게 처리한 `tools-borderless.png`를 연결했다. 9종 모두 테두리 제거본으로 연결됐다. 원본은 유지한다.

도구 트레이는 2172×724 크기를 유지하고 RGB 채널은 변경하지 않았다. 투명 공간에 연결된 밝은 부분과 경계 24픽셀 이내의 크림색을 대상으로 알파 채널을 수정했다. 70,523개 픽셀의 투명도를 변경했으며 재인코딩 후 알파 채널 일치 검사를 통과했다. `qa/tray-border-proof.png`는 회색 배경 합성 확인본이며 서비스에는 투명 PNG만 사용한다.

## 공통 최종 편집 프롬프트

Use case: precise-object-edit. Input image is the edit target. Remove ALL white/cream die-cut sticker borders and halo around the illustrated objects, including borders inside furniture openings and gaps between leaves/objects. Keep the original colored artwork, dark ink contours, exact camera perspective, arrangement, proportions, color, texture and framing unchanged. Preserve glass highlights and naturally pale material INSIDE objects. Output clean isolated artwork on genuinely transparent RGBA background, all empty gaps transparent. No white outline, no cream outline, no checkerboard, no backdrop, no shadow. Do not add or remove objects.

## 식물 묶음 3종의 추가 배경 추출 프롬프트

Remove the checkerboard background. Return the exact illustrated objects as a cutout on a transparent background. PNG with actual alpha transparency. Preserve the dark object edges and original arrangement. Do not add a white border or sticker outline. All space outside objects and between leaves must be transparent, not a depicted checkerboard.

도구 트레이는 같은 요청과 별도의 투명 배경 추출 및 원본 재편집을 시도했으나 배경 문제로 제외했다.
