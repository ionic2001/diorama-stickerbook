# Diorama Stickerbook

투명 스티커를 입체적인 공간 배경에 배치해 나만의 장면을 만드는 브라우저 기반 디오라마 스티커북이다.

현재 온실 정원과 비 오는 밤의 카페 테마를 제공한다. 스티커 이동·크기·회전·반전·레이어 조절, 실행 취소와 다시 실행, 테마별 브라우저 자동 저장, Web Audio 배경음과 PNG 내보내기를 지원한다.

```sh
npm install
npm run dev
npm run verify
```

이 프로젝트는 QK Tool Hub의 `d7b42763cb1d7ae8dcb742f58178246ce1aaa6ea` 커밋에서 독립 프로젝트로 분리했다. 제품 범위와 다음 작업은 [최종 기획서](docs/project/FINAL_PRODUCT_PLAN.md), 제작 과정은 [개발 인수인계](docs/project/DEVELOPMENT_HANDOVER.md)를 참고한다.
