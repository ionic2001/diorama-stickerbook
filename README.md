## 독립 페이지 및 배포

한국어는 `/`, `/themes/`, `/how-to/`, `/features/`, `/about/`, `/privacy/`, `/terms/`, `/ad-settings/`를 사용하며 영어는 같은 경로 앞에 `/en`을 붙인다. 작업실은 `/studio/?set=glasshouse-botanist` 또는 `/studio/?set=rainy-night-cafe`다. 메뉴는 실제 링크이며 각 페이지는 새로고침과 직접 접속을 지원한다. 개인정보 안내와 약관은 검색 가능한 정보 페이지, 광고 설정은 `noindex` 유틸리티 페이지다.

`npm run build`는 설명 페이지 본문과 메타데이터를 HTML에 미리 출력한다. 배포할 때 환경변수 `SITE_URL`에 실제 운영 사이트의 origin(예: 확정 도메인의 https 주소)을 설정하면 canonical·언어 대체 링크·구조화 데이터·sitemap.xml을 생성한다. 도메인을 설정하지 않은 미리보기 빌드는 noindex다. 존재하지 않는 경로에는 호스팅의 실제 404 응답을 사용하고 모든 주소를 홈으로 돌리는 catch-all rewrite는 추가하지 않는다.

출시 빌드 전 `src/legal.config.json`의 운영 주체와 문의처를 채워야 한다. 값이 비어 있는데 `SITE_URL`을 설정하면 빌드가 실패해 검토본이 실서비스로 배포되는 것을 막는다. 현재 광고·분석 SDK는 연결하지 않았으며 `/ad-settings/`는 그 상태와 브라우저 기기 저장 범위를 그대로 보여준다. AdSense를 연결할 때에는 실제 광고 제공자와 처리 내용을 개인정보 안내에 반영하고 적용 지역용 CMP를 먼저 구성한다.

## 2026-09 편집·음악 수정

### 승인된 광고 배치

홈의 테마 소개 뒤, 테마 페이지의 선택 영역 아래, 이용방법 본문 끝에 각각 광고 자리 하나를 구성했다. 작업실·특징·About·법적 페이지에는 배치하지 않는다. 실제 광고 제공자는 연결하지 않았으므로 일반 접속에서는 광고 자리와 여백이 나타나지 않는다. `/?ad-preview=1`, `/themes/?ad-preview=1`, `/how-to/?ad-preview=1`에서 실제 서비스 레이아웃에 적용된 샘플을 확인한다. 영어도 같은 옵션을 지원한다. 미리보기는 동의 정보나 쿠키를 저장하지 않고 광고 요청도 보내지 않는다. 실제 AdSense 연결과 동의 연동, 미충전 처리 및 레이아웃 이동 검증은 후속 작업이다.

미리보기 빌드의 `noindex`가 브라우저 실행 후에도 유지되도록 수정했다.

- PNG 저장은 현재 세트의 자산 목록을 받아 온실·카페 스티커를 함께 합성한다. 누락 자산이나 이미지 로딩 실패 시 불완전한 배경 파일을 저장하지 않고 오류를 표시한다.
- 선택 도구를 작품 영역 밖에 배치했다. 회전 버튼·크기·레이어 조작은 스티커 위치나 화면 축소와 무관하게 접근할 수 있다.
- 곡 선택과 재생 버튼을 구분했다. 명시적 재생 동작에서 오디오 컨텍스트를 시작하고 실패 상태를 표시한다. 음량 변경은 재생을 시작하지 않으며, 탭을 숨기거나 재방문하면 음악이 자동 재생되지 않는다.
- PNG는 정지 이미지다. 배경음·움직임·편집 가능한 스티커 데이터는 PNG에 포함되지 않는다.
- `npm run verify`는 빌드, 기존 레이어/히스토리 테스트와 정적 HTML 검증을 실행한다. `scripts/test-browser.cjs`는 Playwright와 설치된 Chrome을 사용할 수 있는 환경에서 실행한다. 로컬 기본 주소는 5174이며 `TEST_BASE_URL`로 변경할 수 있다. 브라우저 테스트는 별도 프로필을 사용하며 실제 사용자의 저장 데이터에 접근하지 않는다.
